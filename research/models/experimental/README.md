# Experimental Models Directory

This directory stores experimental research model checkpoints, fine-tuned adapters, and Ghanaian-language model variants.

## Boundaries
- Models in this directory are strictly for research and evaluation purposes.
- Experimental models MUST NEVER be directly deployed into `kasa_me/assets/models/` without formal promotion, testing, and approval.
- Experimental models must not overwrite or replace the frozen production model (`english_edge_v1`).
